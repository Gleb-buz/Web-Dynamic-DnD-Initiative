# D&D Dynamic Initiative Tracker

Локальный браузерный трекер инициативы для D&D. Поддерживает динамические броски инициативы, фиксированную инициативу, ресурсы персонажей, спасброски от смерти, статусы существ, светлую/тёмную тему и сохранение всего состояния в `localStorage`.

## Запуск

```bash
npm install
npm run dev
```

Сборка для production:

```bash
npm run build
```

Для Vercel конфигурация находится в `vercel.json`. Проект собирается на Node.js 24, команда сборки — `npm run build`, выходная папка — `dist`.

## Управление

- Добавьте существ и заполните ресурсы.
- Выберите динамическую или фиксированную инициативу.
- Нажмите `Бой`, затем переключайте активный ход стрелками.
- На последнем доступном участнике появится кнопка нового раунда.
- При HP ниже 0 существо находится при смерти и получает спасброски.
- При HP ровно 0 или трёх успехах существо становится `Стабилизирован` и пропускается в очереди.
- Стабилизированному существу можно поднять HP прямо из карточки, после этого оно возвращается в бой.
- Три провала дают статус `Мёртв`: карточка зачёркивается, пропускается в очереди и получает кнопку `Воскресить`.
- `Воскресить` сбрасывает спасброски, ставит HP 1 и возвращает существо в бой.
- Кнопка темы находится в правой части верхней панели.
- `Сброс` полностью очищает трекер и локальное сохранение.
