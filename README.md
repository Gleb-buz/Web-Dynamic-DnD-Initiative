# D&D Dynamic Initiative Tracker

Одностраничное приложение для ведения боя в D&D с поддержкой динамической инициативы, death saves и локальным сохранением состояния.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Управление
- Переключатель «Динамическая инициатива» задаёт режим инициативы.
- Кнопка «+ Добавить» открывает форму создания карточки существа.
- «Бой» запускает бой и сортирует карточки по инициативе; активная карточка раскрывается.
- В бою используйте кнопки навигации «Назад» / «Вперёд»; на последней карточке появляется «Новый раунд».
- При HP ≤ 0 появляются контролы death saves (успехи/провалы) и инициатива замораживается.
- «Сброс» очищает все данные и localStorage.
